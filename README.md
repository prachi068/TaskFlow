 
SMART TASK MANAGEMENT SYSTEM

Project Overview:
A full-stack web application developed to help users and teams efficiently manage, organize, and track tasks. The system improves productivity through task assignment, status tracking, team collaboration, and secure user authentication.

Frontend:
• Developed using React.js and Vite.
• Responsive and user-friendly dashboard interface.
• Login and Registration pages.
• Task creation and management screens.
• Team management interface.
• Task status visualization and tracking.
• Search and filtering functionality.
• Real-time UI updates for better user experience.
• Integrated API communication using Axios.

Backend:
• Developed using Node.js and Express.js.
• RESTful API architecture.
• User authentication and authorization.
• JWT-based secure login sessions.
• CRUD operations for tasks and teams.
• Middleware for request validation and security.
• Error handling and API response management.
• Role-based access control for users.

Database:
• MongoDB database for data storage.
• Mongoose ODM for schema management.
• Stores user information.
• Stores task details and status.
• Stores team information and assignments.
• Maintains relationships between users, teams, and tasks.

Core Features:
• User Registration and Login.
• Secure Authentication using JWT.
• Create, Update, Delete, and Manage Tasks.
• Task Priority Management.
• Task Status Tracking (Pending, In Progress, Completed).
• Team Creation and Team Management.
• Assign Tasks to Team Members.
• Search and Filter Tasks.
• Dashboard for Monitoring Tasks.
• Responsive Design for Multiple Devices.

Technical Skills Demonstrated:
• Full-Stack Web Development.
• REST API Development.
• Authentication & Authorization.
• Database Design and Management.
• State Management in React.
• Frontend-Backend Integration.
• CRUD Operations.
• Secure Application Development.

Technology Stack:
Frontend: React.js, Vite, Axios, CSS/Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB, Mongoose
Authentication: JWT (JSON Web Token)
Version Control: Git & GitHub
